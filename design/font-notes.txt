Preparation:
Downloaded the matching normal and real italic variable font files from Google Fonts.
Fixed width (wdth) at its original normal 100% value. Kept the weight axis 100–900,
default 400. Subset each complete face to Latin, Latin Extended, Vietnamese,
combining accents, common punctuation/currency and symbols, retaining shaping
features. Encoded to WOFF2. Each style has a single file containing both Latin and
Vietnamese, so the Vietnamese diacritics do not switch to a separate face.

Verification:
Both output faces were reopened with fontTools. All U+1EA0–U+1EF9 characters,
Ă/ă, Đ/đ, Ĩ/ĩ, Ũ/ũ, Ơ/ơ, Ư/ư, and the Vietnamese combining accents are present.
The sample below is fully supported in both composed NFC and decomposed NFD form.
Regular contains 1,122 cmap entries; italic contains 1,121. The italic angle is
-12 degrees in the actual font; regular is 0. Only the weight variation axis remains.

Observed prior setup:
The Cormorant Garamond Latin and Vietnamese files were matching upright variable
fonts (weight 300–700, italic angle 0). The website's italic emphasis therefore
relied on browser synthesis. File metadata does not by itself prove why every
diacritic appeared wrong in the supplied screenshot. The replacement removes this
synthetic style, uses complete Vietnamese coverage within each face, and fixes the
font width. The page should also use comfortable line height and no text scaling.

Body font completion:
The prior split Be Vietnam Pro subsets covered composed NFC Vietnamese, but omitted
the decomposed circumflex, breve and horn marks U+0302/U+0306/U+031B. The official
full font files contain these glyphs. Downloaded and WOFF2-encoded each complete
file, without glyph subsetting or shape modifications. All four contain 459 cmap
entries and cover the complete Vietnamese test above in both NFC and NFD form.
